# 🎵 Ostinato — Lightweight Gaming Music Player

**Ostinato** — ультралегкий автономный десктопный аудиоплеер с поддержкой библиотеки Яндекс Музыки и локальных файлов, написанный с нуля на чистом **Rust** (`egui` + `rodio`).

работает на фоне тяжелых игр (CS2, Dota 2, Valorant, Rust) без просадок FPS, встроенных браузеров Electron и лишней нагрузки на видеокарту.

---

## 📊 Сравнение потребления ресурсов

| Клиент | Активный режим | Фоновый режим («Супер-сон») | Вес программы |
| :--- | :---: | :---: | :---: |
| **Официальный клиент (Electron)** | ~300–550 МБ ОЗУ | ~250–350 МБ ОЗУ | ~350 МБ |
| **Ostinato (Native Rust)** | **~18–22 МБ ОЗУ** | **~4.9 МБ ОЗУ (0% GPU)** | **~8.5 МБ (1 `.exe`)** |

---

## ⚡ Ключевые возможности

* **Режим «СУПЕР-СОН» (~4.9 МБ ОЗУ):** одной кнопкой или хоткеем полностью отключает рендер окна (`0% GPU`), переводит процесс в аппаратный энергоэффективный режим Windows `EcoQoS`, очищает рабочий набор памяти и сворачивается в значок системного трея возле часов.
* **Глобальные бинды поверх полноэкранных игр:** мгновенное управление паузой, переключением треков, лайками, встряской волны и сном прямо во время матча (поддерживаются `Numpad`, `F1–F12`, стрелки и модификаторы).
* **Полная синхронизация библиотеки:** подгрузка «Мне нравится», пользовательских плейлистов, обложек альбомов и бесконечного потока рекомендаций **«Моя волна»**.
* **Живой поиск и карточки артистов:** быстрый поиск треков и исполнителей + переход к популярным трекам артиста по клику прямо под обложкой играющей песни.
* **Офлайн-режим:** воспроизведение локальной папки с музыкой (`MP3`, `FLAC`, `WAV`, `OGG`) без интернета и авторизации.
* **Безопасность и приватность:** вход выполняется по одноразовому коду устройства на официальном сайте Яндекса без ввода пароля в программу. Токен и настройки хранятся строго локально на ПК пользователя в `ostinato_config.json`.

## 📥 Скачать и запустить (Windows 10 / 11)

Ничего устанавливать не нужно — программа работает портативно из одного файла:

1. Перейдите в раздел **[Releases](../../releases)** справа и скачайте последний архив **`Ostinato.zip`** (или чистый `Ostinato.exe`).
2. Распакуйте `Ostinato.exe` в любую отдельную папку (например, `C:\Games\Ostinato`) и при желании создайте ярлык на Рабочий стол.
3. При первом запуске (если появится окно фильтра Windows SmartScreen из-за отсутствия платного сертификата подписи) нажмите **«Подробнее» → «Выполнить в любом случае»**.
4. Нажмите **«Получить код и войти»** и подтвердите код на странице в браузере.

## 🎮 Горячие клавиши и управление

* **Настройка биндов:** откройте нижнюю вкладку настроек на левой панели, нажмите на действие и задайте любую удобную клавишу (`Esc` — отмена). *Для цифр бокового блока держите включенным `NumLock`.*
* **Громкость:** наведите курсор на иконку динамика для вызова вертикального ползунка (поддерживается прокрутка колесиком мыши). Клик по динамику — `Mute`.
* **Возврат из Супер-сна:** нажмите **левой кнопкой мыши** по сине-черному значку **Ostinato** в системном трее у часов (или нажмите назначенный бинд Супер-сна).
* **Полный выход:** крестик `✕` в правом верхнем углу окна или **правый клик** по значку в трее → **«Выйти полностью»**.

## 🛠 Сборка из исходного кода (для разработчиков)

Если вы хотите собрать проект самостоятельно из исходного кода:

```bash
git clone https://github.com
cd Ostinato
cargo build --release
```
Готовый исполняемый файл появится по пути `target/release/ym_light_player.exe`.
